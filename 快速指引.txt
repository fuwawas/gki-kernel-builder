================================================================
 GKI 内核编译工具 —— 快速指引
================================================================

【第 0 步】查出你的内核版本号（这步填错全白干）

  手机开 USB 调试插电脑，电脑上执行：

      adb shell cat /proc/version

  不想用电脑：手机 设置 → 我的设备 → 全部参数 → 内核版本

  会看到类似这样一串：

      Linux version 6.1.138-android14-11-...

  拆三段记下来：

      android14  <- 第①段（Android 分支前缀）
      6.1        <- 第②段（内核主版本）
      138        <- 第③段（子版本号，最关键，必须一字不差）


----------------------------------------------------------------
【方式 A】推荐 · 云端编译（电脑可以关，约 30-50 分钟）
----------------------------------------------------------------

  1) 浏览器打开：https://github.com/fuwawas/gki-kernel-builder
     点右上角 Fork，全部保持默认，仓库名不要改

  2) 【必做！不然一定失败】
     进你自己 fork 出来的仓库 → Actions 标签页 →
     点绿色按钮 "I understand my workflows, go ahead and enable them"
     （GitHub 对 fork 仓库默认关掉 Actions，只做这一次）

  3) 还在 Actions 页面：
     左边点 "Build GKI Kernel (Droidspaces)"
     右边点 "Run workflow" ▾
     填：
        Android 内核分支前缀 = 第①段  android14
        内核主线版本         = 第②段  6.1
        子版本号             = 第③段  138
        内置 root 方案       = ReSukiSU
        Droidspaces 槽位     = 678
        CVE-2026-43499 修复链 = 勾上
        ZRAM LZ4KD           = 别勾
        其余全部默认
     点绿色 Run workflow

  4) 等 30 分钟左右回来刷新。
     run 页面中间会直接显示参数和刷机命令
     页面最底下 Artifacts 区下载刷机包

----------------------------------------------------------------
【方式 B】本机命令行（装了 WSL 或 Linux）
----------------------------------------------------------------

  在这个文件夹里打开终端：

      chmod +x gkibuild.sh
      ./gkibuild.sh

  不带参数会进向导，一步步问你选什么，第一次建议这么用。

  熟了可以一条命令：

      ./gkibuild.sh -v android14-6.1-138

  源码会缓存下来，重编不用再拉 2.2GB。
  想换缓存位置（比如盘不够）：

      ./gkibuild.sh -v android14-6.1-138 --cache-dir D:/kernel-cache

  产物在 gki-out 文件夹。

----------------------------------------------------------------
【方式 C】Docker（本机不用装任何编译依赖）
----------------------------------------------------------------

      ./docker-run.sh -v android14-6.1-138

  注意：Docker Desktop 要先去 Settings → Resources 把内存
  调到 8GB 以上，默认 2GB 一定编不动。

----------------------------------------------------------------
【方式 D】Windows 双击（可选，能自动下载产物）
----------------------------------------------------------------

  1) 装 gh CLI：https://cli.github.com
  2) 命令行跑一次：gh auth login
  3) 双击本文件夹里的 启动编译.bat


================================================================
 拿到刷机包之后 —— 风险自负
================================================================

1. 先备份原厂 boot（没备份千万别动手）

     adb shell su -c "dd if=/dev/block/bootdevice/by-name/boot of=/sdcard/boot_stock.img"
     adb pull /sdcard/boot_stock.img

2. 刷入（Recovery 里刷那个 zip，或者）

     adb reboot bootloader
     fastboot flash boot Image
     fastboot reboot

   小米还要处理 vbmeta：

     fastboot --disable-verity --disable-verification flash vbmeta vbmeta.img

3. 卡开机动画了 —— 这是正常的，不是你操作错了

   Droidspaces 会破坏 GKI ABI，导致厂商驱动加载不了。
   换槽位重新编译就行：678 → 123 → 345

   救急：开机第一屏后连按音量减 3 次（按-松-按-松-按-松）
        进 KernelSU 安全模式卸掉问题模块
        最后手段：fastboot flash boot boot_stock.img


================================================================
 常见问题
================================================================

Q：点了 Run workflow，页面一片空白？
A：Fork 后没启用 Actions，回到方式 A 第 2 步。

Q：脚本报找不到仓库 / 403？
A：gh 登录的账号和 fork 到的账号不是同一个。执行 gh auth status 看看。

Q：要花钱吗？
A：不用。GitHub 免费账号每月 2000 分钟，一次编译 30-50 分钟。

Q：能给别的手机编吗？
A：能，把那台手机的 /proc/version 输出拿来，按那个版本号编就行。

Q：国内下载慢？
A：脚本会自己测速挑最快的 GitHub 镜像。手动指定：
     --mirror https://gh-proxy.com/

Q：编安卓 16 / 6.12 的内核行吗？
A：小米别编。上游明确说 6.12 的产物米系设备用不了。
